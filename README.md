# Puli Meka

A Flutter Android game of tigers and goats.

## Build the APK

Install Flutter, then run:

```shell
flutter pub get
flutter build apk --release
```

The APK is created at `build/app/outputs/flutter-apk/app-release.apk`.

## Build on GitHub

Push to `main` or `master`, or start **Build Android APK** from the Actions tab.
The workflow builds and uploads the release APK as a downloadable workflow
artifact.
